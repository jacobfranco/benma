# SpeechSuper Mandarin evaluation

- Research checked: 2026-08-03
- Lifecycle: `DOCUMENTED`
- Implementation/live status: not implemented; trial/account and usable API contract unavailable

SpeechSuper's public Mandarin demonstrations visibly distinguish initials, finals, target versus
detected sounds, tone, tone score, character feedback, and sentence tone accuracy. That makes it a
useful candidate for an independent commercial comparison. The public developer documentation was
client-rendered/incomplete in this environment, and no trial credential or real response was
available. A demo UI is not a stable API schema.

Do not stall the calibration campaign on a sales workflow. To advance this provider, request a
trial and obtain the exact endpoint, authentication scheme, Mandarin task identifiers, audio
format, response schema, model/version disclosure, rate/concurrency limits, pricing, regional
processing, retention, deletion, and sanitized-fixture permission. Only then add a transport and
contract fixtures. Current status is not `IMPLEMENTED` and not `LIVE_VALIDATED`.
