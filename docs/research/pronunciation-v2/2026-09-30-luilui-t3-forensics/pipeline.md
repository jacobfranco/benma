# Pipeline, drawer, and measurement definitions

This adapter calls existing production code. It does not implement another pitch tracker. Paths below are relative to the repository root; exact source hashes are in `provenance.json`.

1. `benchmark/pronunciation_v2/v1_adapter.py` establishes the frozen comparison: ffmpeg mono 16-kHz PCM16 without trimming, `PraatAcousticAnalyzer`, `classify_contour(..., start=0, end=decoded_duration, timing_reliable=True)`. The new adapter reproduces that local route. The original audio is read only; canonical WAVs exist only in automatically removed temporary directories.
2. `services/api/src/benma_api/pronunciation/acoustics.py` runs Praat autocorrelation with floor 50 Hz, ceiling 550 Hz, 10-ms step, voicing threshold .45, octave-jump cost .5, octave cost .01, voiced/unvoiced cost .14, silence threshold .03, and up to 15 candidates. It stores pre-gate `tracker_f0_hz`, gated `f0_hz`, selected strength, RMS, candidates, a 70-Hz high-pass comparison track, spectral low-frequency fraction, disagreement and selection flags. The comparison track never replaces F0. Energy gating is bounded by the recording's noise floor and peak RMS. The narrowly defined terminal ambiguity rejection never manufactures pitch. No parameters changed.
3. `contours.py:display_contour` checks quality usability, finite values, frequency range and confidence. It rejects short islands >6 st bracketed by agreeing neighbors and isolated local Hampel outliers with bilateral support. Missing/rejected points break segments. It recomputes a retained-pitch median baseline and applies median-of-three smoothing within segments. Raw Hz is not rewritten. `filtered_measured_frames` stores original surviving Hz and a separate smoothed-semitone field at every original timestamp, with nulls for missing/rejected samples.
4. `evidence_region.py:select_tone_evidence` can exclude only independently supported weak attacks or fading contaminated tails, using energy/periodicity and comparison-track agreement, never spelling, tone, or desired shape. It selects no narrower region in this dataset. Interior creak/dropouts remain inside the evidence region.
5. `contours.py:classify_contour` discards its caller-supplied display argument and rebuilds full-resolution reliable evidence from raw points. It computes coverage, gaps, raw jumps, disagreement, residuals, five equal-count median bins, and quality gates before assigning a broad shape. A production “jump” compares successive voiced frames no more than .12 s apart; it can span missing frames. `adjacent_large_jump_count` is separately restricted to adjacent original 10-ms frames. Neither value is proof of an octave mistake. The category uses relative semitones and broad temporal geometry, not lexical identity or a direct voice-quality classifier.
6. `laboratory.py` resolves accepted timing, slices per syllable, classifies on raw evidence, and returns a simplified syllable display (≤.15-st vertex-deviation tolerance with a retained-core boundary preserved). Whole-utterance detail retains the full display. `timing.py` requires valid identities/provenance and accepted provider timing; it can accept unchanged provider spans with independently supported recording padding, but does not invent spans. This research adapter bypasses that orchestration under the known isolated-syllable assumption. It does not fake `live_provider`/`live_tool` provenance or call alignment.
7. `interpretation.py` is a separate provider/target comparison path: expected tone can be compared after acoustic measurement, but it is not the target-independent contour classifier. `diagnostic.py` recomputes classifier/evidence-region information for inspection. No DB-backed laboratory, interpretation service, cloud adapter, or live assessment is invoked here.
8. `PronunciationFeedback.tsx` passes per-syllable display/observation to `SyllableComparison.tsx`; detail shows both whole-utterance server display and raw `f0` (falling back to `mobile_f0`). The latter is normally min/max bucket-downsampled with gaps preserved, at most 240 points. These short clips are below the cap. `primaryMineContour` first tries `learnerGestureContour`; otherwise it may crop to an explicitly selected evidence region/core. Its input contains no expected tone for contour generation.
9. `learnerGestureContour.ts` may replace a continuous contour with the classifier's five bin medians and their representative times. These points are summaries, not individual pitch measurements. It requires no gaps, or a separately certified short coherent gap. `normalizedDisplayContour.ts` applies .2/.6/.2 smoothing to non-bin displays while preserving endpoints and substantial extrema, recenters on the display median, and uses a symmetric extent of at least ±4 st. It can merge certain short coherent gaps for drawing only. The backend and measured output never receive those lines.
10. `PitchPlot.tsx` uses supplied display segments, otherwise raw pitch segments with explicit null breaks and a .045-s maximum temporal step. It draws straight segments. Primary Mine uses `fitVoiced` to stretch the retained/summary time range to the thumbnail, and fixed relative display limits in target feedback. Expected is a separately drawn lexical teaching shape (T3 heights .25, 0, .75; T4 1, 0). In research plots this reference is overlaid only after extraction, with arbitrary teaching amplitude and an explicit label; it is not fitted to the measurements or claimed to be a reference recording.

`drawer_projection.cjs` transpiles and executes the actual existing mobile helper modules in a local Node VM. React Native layout/style imports are stubs; UI components are not mounted. Acoustic transformations, verdict logic and lexical shapes are imported, not copied. JSON includes full diagnostic data, a `drawer_input_subset` with the acoustic fields in mobile API shape, and separate `drawer_projection` geometry. The subset is not a complete authenticated live response: no IDs, cloud assessment, synthetic live timing, or reference recording is invented. `display_pinyin` uses frozen numbered-pinyin metadata, so typography may differ from a live diacritic-formatted target. The waveform, timing, contours, and projections remain independently inspectable.

## Diagnostic conventions

- Frame fractions use the number of Praat output frames, not waveform samples or full duration. Raw `f0_hz=null` stays null. Tracker windows leave a small amount of audio outside the first/last frame; this is not fabricated as extra observed frames.
- Gap duration is missing-frame count ×10 ms. Internal gaps exclude leading/trailing missing runs. For example, one missing frame is 10 ms, while production `longest_gap_seconds` measures endpoint-to-endpoint separation (20 ms in that example). Both are saved, with different names. Plot shading shows half-hop support around absent frame centers; it does not assert an exact glottal boundary.
- The research energy-active mask is `RMS >= max(production energy threshold, .2 × maximum frame RMS)`, borrowing the existing timing validator's activity convention. It affects only descriptive denominators and energy summaries, never extraction, timing, evidence selection, or classification. It is not a vowel/nucleus aligner. Onset, middle and ending RMS are equal-time thirds of its first-to-last frame interval, including interior low-energy frames.
- Temporal shape summaries use first-to-last available voiced timestamps, with equal-time thirds, ignoring missing observations inside each third. A third with no observations stays null. No interpolation supplies a missing mean. Production bins instead contain equal counts of retained frames, an explicitly different summary. Raw semitones use the utterance's raw voiced median; retained semitones use the retained median and production smoothing. Minimum position uses the first minimum; raw and retained values can differ slightly because smoothing creates plateaus. For direct overlay the plot recomputes raw semitones on the same retained baseline and labels that choice.
- `voicing_probability` is selected-candidate autocorrelation strength, despite the field name. Active-frame mean includes unvoiced selections; voiced-only mean conditions on a successful F0 estimate and therefore has selection bias. “Low confidence” here means voiced strength <.65, a fixed descriptive threshold, not a new production gate.
- An octave candidate is counted if it lies within 1 st of half/double selected F0, has strength ≥.45, and is within .10 strength below the selected value (or stronger). Ordinary periodic sounds have subharmonic candidates, so this is an ambiguity indicator, not a creak score or validated error detector. The .10 threshold was not optimized against labels.
- `longest_tracked_period_ms = 1000 / minimum tracked Hz` reports the selected branch period; it is not a measured glottal closure interval. Adjacent-frame F0 deltas are not pulse jitter. No new HNR, CPP, pulse-train extractor, neural F0, or clinical phonation assessment was added.
- Whole-recording RMS/peak/clipping use canonical PCM16 values. The production silence fraction uses frame RMS <.003 and is distinct from the adaptive energy gate. Recorded amplitude does not establish vocal effort or pressure. No T3/T4 pair matching controls consonants, vowels, word identity, gain, or recording conditions.
- Distributions are unweighted per-clip summaries, not pooled-frame statistics. The source-level sample is one speaker. Quarter quantiles use NumPy's standard linear interpolation; n=2 subgroup quartiles should not be interpreted as stable distribution estimates.

## Artifact semantics

All 34 plots retain missing spans in measured panels. Purple dashed geometry is display-only, orange dashed geometry is a teaching reference, green Hz points are original measurements surviving the production filter, and green semitone curves are explicitly production-smoothed estimates. The drawer panel preserves actual timestamps on the full-file axis for auditing, while the phone thumbnail stretches its own voiced/summary interval. It is an information/geometry reproduction, not a pixel-identical screenshot.

Standalone SVGs and the local HTML gallery have no external resources or runtime network dependencies. Matplotlib/Plotly/gnuplot were unavailable in the inspected environments; a small SVG writer avoided adding a dependency or contacting a package registry. Existing ImageMagick was used only to rasterize selected SVGs into `/tmp` for visual inspection. No audio listening was performed by the agent.
