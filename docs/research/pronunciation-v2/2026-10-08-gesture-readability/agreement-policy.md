ambiguous, and the separate geometry prototype fails its regression gate. No
agreement/color prototype or production implementation followed.

The current centralized `pitchAgreement` still returns `UNAVAILABLE` for every
unit; `unitPresentation` remains neutral. Strict integrity and current experimental
observed-gesture semantics are unchanged. No numeric score, red state, or whole
pronunciation correctness claim is introduced.

The requested future meanings are retained as requirements, **not executable rules**:

| Reserved state / future treatment | Required evidence |
| --- | --- |
| STRONG_MATCH / green | Readable supported gesture, trustworthy acoustics, strong compatibility with contextual expected surface realization. |
| PARTIAL_OR_FLEXIBLE / amber | Supported but weaker/mixed compatibility, or context allowing multiple realizations. Uncertainty alone is not a partial match. |
| CLEAR_DIFFERENCE / orange | Readable trustworthy evidence with a strong contextual conflict. Mixed measurement alone cannot trigger it. |
| UNAVAILABLE / gray | Insufficient basis to judge pitch-gesture agreement. |

Any later comparison must use the existing contextual surface engine. Connected
Tone 3 may be low/partial, dipping, or sandhi-rising; no textbook U is demanded.
Neutral tone has no fixed dramatic contour and cannot be penalized for lacking one.

label would describe acoustics only; it must not infer lexical T1/T2/T3/T4.

no per-unit graph, playback, readability or grade (`d47274bc`). Target 广州 and
perceived 贵州 retain 贵州 ownership; target-relative textual differences stay separate.

## Learner copy and accessibility

No new copy shipped. The existing empty graph says **“Not enough pitch signal”**,
not “we did not hear the syllable.” 个 retains its perceived identity, reading,
accepted timing, and **Play my recording for 个** control. Measurement/gesture text
names pitch support separately. This meets the requested speech-versus-pitch
distinction without an unnecessary UI change; the physical regression verifies
the empty pitch graph coexists with exact playback.

alongside “Measurement: mixed,” with scope limited to supported selected evidence.

details / Raw. Existing accessible unit labels, selected state, playback names,
and neutral presentation remain intact and regression-tested. A later color release
must include a textual pitch-agreement equivalent; color alone is insufficient.
