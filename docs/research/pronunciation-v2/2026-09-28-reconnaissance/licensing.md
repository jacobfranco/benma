# Licensing and provenance decision record

Checked 2026-09-28. This is documentary due diligence for selecting experiments, not a legal opinion. **GREEN:** documented relevant commercial uses appear permitted throughout the identified lineage. **YELLOW:** conflict, missing provenance or scope question needs resolution. **RED:** an explicit incompatible restriction applies. Confidence describes our evidence, not a probability of winning a legal dispute. No permission is inferred from silence. Being downloadable, “open source,” research-only use inside a company, or a permissive code license does not settle data/weight rights.

The **recommended encoder path is GREEN** at this documentary level. A broad public native training source plus pretrained Mandarin aligner was **not verified GREEN end to end**. A directly licensed native collection with manual annotation avoids those dependencies but is not an existing cleared asset. OMPAL is a useful publicly permitted learner-evaluation source, subject to ordinary provenance checks below.

## Exact decisions requiring a human/legal owner

1. **CV v27 acquisition:** does the intended private Benma commercial tone-training workflow, including canonical copies, syllable crops, cached embeddings and distribution of a small classifier head, fit the dataset-specific card and current MDC terms? Does no-resharing prohibit any planned review bundle? Do not assume old mirrored HF access terms apply to a new acquisition.
2. **AISHELL-1 / THCHS-30:** does the data owner intend unrestricted Apache commercial ML rights, or is the academic-use text a limitation? Obtain release-specific written clarification if choosing them.
3. **AISHELL-3:** obtain the current publisher product/license text and archive notices; reconcile original versus expanded release identities. Is any research-only provision applicable to the exact audio? It was not verified here.
4. **Tencent/WenetSpeech:** what grant covers commercial learned weights and underlying web recordings despite the corpus's NC wording and reservation of third-party copyright? Do not ask only whether MIT permits commerce.
5. **WavLM:** which license covers the exact HF Base checkpoint and any distributed head/fine-tuned bundle: the linked CC BY-SA-3.0 or original MIT? What is considered an adaptation?
6. **XLSR/MFA:** do each of BABEL / AI-DataTang / other training-source agreements authorize the proposed pretrained-model commercial use? The report flags risk, not an automatic legal conclusion that training-data licenses propagate to outputs.
7. **FLEURS:** preserve the precise FLORES-101 translation grant and any share-alike obligations; distinguish audio, text and derived annotations. No automatic relicensing of source text from a top-level card.
8. **OMPAL:** confirm participant consent scope if broadening beyond ordinary private evaluation; verify prompt/text reuse rights before redistribution. Corpus copyright permission is unusually explicit, but does not independently document each release form.
9. **New recordings:** approve a short grant/consent covering the exact workflow above, duration/storage and deletion handling. No signing, contacting speakers, payments or collection was done in this pass.

None of these questions authorizes new provider calls, purchases, messages or use of uncertain assets. The reconnaissance itself is complete; a data gate in a future experiment is not a request to stop documenting its concrete design.
