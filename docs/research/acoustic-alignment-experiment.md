# Acoustic and forced-alignment experiment status

Date: 2026-08-03.

## What was executed

The dependency-free autocorrelation analyzer was executed in automated tests on deterministic
mono PCM16 calibration signals. A 200 Hz voiced signal is recovered within 4%, silence remains
unvoiced, speaker-relative semitone/z-log normalization is populated, and static SVG output
contains waveform plus F0. These are engineering sanity checks, not Mandarin tone evidence.

The harness also implements optional torchcrepe and Praat/Parselmouth analyzers behind the same
`PitchAnalyzer` contract. No heavy model/runtime was installed in the core environment, so no
numerical agreement claim is made. torchcrepe documentation's silence-confidence caveat is the
reason energy/periodicity and missing F0 remain visible.

Run `python -m benchmark acoustics` after each recording; the output path should include sample ID,
speaker ID, algorithm, and version. Overlay a same-target native reference only when timing is
normalized and the report labels it as a comparison rather than a canonical curve.

The checked-in files under `benchmark/reports/fixtures/acoustics` are generated by
`python -m benchmark acoustic-fixtures`. They are pure sinusoids labeled “SYNTHETIC CALIBRATION”;
they demonstrate engineering behavior and must never be used as Mandarin phonetic references.

## Forced alignment

MFA's current Mandarin model family and licenses were reviewed, an isolated `align_one` adapter was
implemented, and TextGrid extraction is fixture-tested. MFA was not installed and the repository
contains zero recordings, so a hand-inspected alignment result cannot truthfully exist yet.

The first review subset is fixed in advance:

- `tone_pair_33`
- `sandhi_33_nihao`
- `sentence_beijing_control`
- `sentence_beijing_wrong_tone`
- `sentence_shuijiao_wrong_initial`
- `sentence_houmian_omission`
- `control_clipped`
- `control_low_volume`

For each, two reviewers should mark word/syllable boundary absolute error, OOVs, beam changes,
gross boundary failures, and whether a UI highlight would be misleading. Keep failed TextGrids.
Fifty hand-labeled utterances, including at least 20 bad learner productions, are required before
trusting precise UI boundaries.

## Current conclusion

There is **insufficient evidence** that F0 adds grading information beyond commercial assessment.
It is retained as visualization/debug evidence. There is **insufficient evidence** that MFA is safe
for pronunciation UI; coarse/provider timing is the temporary substitute. These gaps block grading
and precise highlights, not continued corpus recording or provider bake-off work.
